# DataConm

DataConm es un middleware empresarial desarrollado por COMPULABT S.A. para procesar, revisar y transferir información entre sistemas ERP y tiendas WooCommerce de forma controlada.

## Versión disponible

La serie 1.x corresponde a una versión gratuita de evaluación y colaboración, sin limitaciones de tiempo o volumen establecidas actualmente.

La primera publicación oficial será:

- Versión: 1.26.10
- Compilación: B0001
- Plataforma: Windows 10 y Windows 11 de 64 bits
- Estado: preparación final

## Funciones principales

- Procesamiento de productos y existencias.
- Integración controlada con WooCommerce.
- Simulación antes de publicar información.
- Administración de categorías.
- Centro de Datos para revisión y exportación.
- Protección de credenciales y datos empresariales.
- Actualizaciones verificadas con respaldo y recuperación.
- Generación de diagnósticos para soporte técnico.

## Compatibilidad

Cada edición de DataConm se prepara para un ERP o una empresa determinada. La compatibilidad debe comprobarse antes de utilizar el sistema con una fuente de datos diferente.

COMPULABT recibe solicitudes para estudiar la integración de otros ERP y formatos de reportes empresariales.
